# ClassMind

> 대학생을 위한 AI 수업 비서
> **수업 중에는 최소한으로 기록하고, 수업 후에는 AI와 함께 이해하고 정리한다.**

---

## 1. 프로젝트 개요

ClassMind는 대학생의 **수업 중 작성한 최소한의 메모**와 **교수님의 강의 자료(PDF)**를 기반으로 수업 내용을 정리하고, 질문과 복습까지 이어갈 수 있도록 돕는 AI 학습 서비스이다.

대학생은 수업을 들으면서 모든 내용을 자세하게 필기하기 어렵다.

ClassMind는 이러한 상황을 전제로 한다.

```text
수업 중
  ↓
최소한의 메모
  ↓
수업 종료
  ↓
AI가 메모와 강의 자료를 분석
  ↓
AI Note 생성
  ↓
학생이 질문
  ↓
Q&A 내용을 AI Note에 반영
  ↓
최종 학습 노트 생성
```

ClassMind의 목표는 학생을 대신해서 공부하는 것이 아니라, **학생이 수업에서 기록한 작은 단서를 학습 과정으로 연결하는 것**이다.

---

# 2. 해결하려는 문제

기존 수업 환경에서는 다음과 같은 문제가 발생한다.

* 수업을 들으면서 충분한 필기를 하기 어렵다.
* 수업 직후에는 이해했지만 시간이 지나면 기억하기 어렵다.
* 강의 PDF가 있어도 어떤 부분을 공부해야 할지 판단하기 어렵다.
* AI에게 질문할 때마다 수업의 맥락을 다시 설명해야 한다.
* 질문과 답변이 기존 노트와 연결되지 않는다.
* 시험 직전에 여러 주차의 내용을 다시 정리해야 한다.

ClassMind는 이를 다음과 같이 해결한다.

| 문제            | ClassMind의 접근    |
| ------------- | ---------------- |
| 수업 중 필기 부담    | 최소한의 메모만 작성      |
| 부족한 필기 내용     | 강의 PDF + AI로 보완  |
| 수업 맥락이 없는 AI  | 과목/주차 기반 Context |
| 질문 내용이 흩어짐    | AI Note에 Q&A 누적  |
| 시험 대비 노트 부족   | Final Note 생성    |
| 중요한 내용 구분 어려움 | 교수님 강조 포인트 활용    |

---

# 3. 핵심 원리

ClassMind의 가장 중요한 원칙은 다음과 같다.

> **학생의 메모가 의도의 기준이며, 강의 PDF와 AI는 이를 보완한다.**

정보의 우선순위는 다음과 같다.

```text
1. 학생의 Original Note
        ↓
2. 교수님의 Lecture PDF
        ↓
3. AI 보완 개념
```

AI가 학생의 메모를 무시하고 임의로 수업 범위를 확장하지 않도록 한다.

---

# 4. 노트 구조

ClassMind는 하나의 노트를 단순히 생성하고 끝내지 않는다.

```text
Original Note
      ↓
AI Note
 + Q&A
      ↓
Final Note
```

## Original Note

학생이 수업 중 직접 작성한 원본 메모이다.

* AI가 수정하지 않는다.
* 원본 그대로 보존한다.
* AI가 수업 의도를 판단하는 중요한 기준이다.

---

## AI Note

Original Note를 기반으로 생성되는 학습 노트이다.

수업 후 학생이 질문하면 해당 질문과 답변을 필요한 부분에 반영한다.

따라서 AI Note는 계속 변화하는 **Living Note** 역할을 한다.

```text
AI Note
   ↓
학생 질문
   ↓
AI 답변
   ↓
관련 Section 수정
   ↓
AI Note 업데이트
```

사용자가 직접 AI Note를 수정할 수도 있다.

AI가 다시 정리할 때 사용자의 수정 내용을 무조건 덮어쓰지 않는다.

---

## Final Note

시험이나 복습을 위해 최종적으로 정리한 학습 노트이다.

Final Note 생성은 기본적으로 사용자의 요청을 기준으로 한다.

```text
AI Note
+
Q&A
+
교수님 강조 포인트
+
중요 개념
      ↓
Final Note
```

---

# 5. AI 보완 개념

AI는 학생의 메모를 기반으로 **필요한 주변 개념만 최소한으로 보완**한다.

기본적으로 1~2개의 연관 개념을 추가한다.

예:

```text
학생 메모

프로세스는 독립적인 메모리를 가지고
스레드는 메모리를 공유한다.
```

AI가 필요한 경우:

```text
AI 보완 개념

- 프로세스 주소 공간
- 컨텍스트 스위칭
```

처럼 주변 개념을 보완할 수 있다.

반대로 현재 수업과 관계없는 운영체제 전체 내용을 추가하는 식으로 범위를 확장하지 않는다.

---

# 6. 메모 신뢰 확인

수업 중 메모는 짧거나 불완전할 수 있다.

예:

```text
세마
```

AI가 이를 무조건 `세마포어`라고 판단하면 잘못된 정보가 이후 노트 전체에 반영될 수 있다.

따라서 의미가 불확실한 경우 사용자에게 확인한다.

```text
"세마"를 "세마포어"로 해석했습니다.

[확인 후 진행]
[직접 수정]
```

판단 기준:

```text
단순 오타
→ 자동 수정

문맥상 명확
→ 그대로 진행

여러 의미가 가능
→ 사용자 확인

의미 판단 불가능
→ 추측하지 않음
```

# 7. 강의 PDF

강의 PDF는 AI가 수업 내용을 보완하기 위한 자료로 사용한다.

PDF가 없는 경우에도 학생의 Original Note만으로 AI Note를 생성할 수 있다.

```text
Original Note
      +
Lecture PDF
      +
AI
      ↓
AI Note
```

## PDF 처리

### 30페이지 이하

PDF 전체 텍스트를 추출하여 분석한다.

### 30페이지 초과

전체 PDF를 매번 AI에게 전달하지 않고 먼저 요약한다.

```text
대용량 PDF
    ↓
1차 요약
    ↓
DB 저장
    ↓
필요할 때 재사용
```

이를 통해 반복적인 PDF 분석에 필요한 토큰 사용량을 줄인다.

---

# 8. Context-aware Q&A

ClassMind의 Q&A는 일반적인 AI 채팅과 다르게 **현재 수업의 맥락을 우선한다.**

질문에 대한 Context는 다음 순서로 찾는다.

```text
현재 주차
   ↓
가장 가까운 이전 주차
   ↓
가장 가까운 다음 주차
   ↓
AI Note
```

같은 과목이라고 해서 모든 주차의 내용을 동일한 비중으로 AI에게 전달하지 않는다.

이를 통해:

* 관련 없는 정보 감소
* 토큰 사용량 감소
* 현재 수업에 맞는 답변
* 개념 간 연결

을 목표로 한다.

---

# 9. Living Note

Q&A가 단순한 대화 기록으로 끝나지 않도록 한다.

```text
질문
 ↓
AI 답변
 ↓
답변과 관련된 AI Note Section 확인
 ↓
필요한 부분만 수정
```

전체 노트를 매번 재생성하지 않는다.

### 업데이트 원칙

```text
1. 관련 Section 수정
2. 필요한 경우 관련 Section 추가 수정
3. 전체 노트는 유지
```

이를 통해 사용자의 기존 수정 내용을 보호하고 불필요한 AI 호출을 줄인다.

---

# 10. 교수님 강조 포인트

교수님이 강조한 내용을 학습 데이터로 활용한다.

예:

```text
시험 나온다
중요
외우기
★
※
```

사용자가 직접 표시할 수도 있다.

```text
⭐ 중요
🔥 시험
📝 복습
❓ 헷갈림
```

이 정보는 이후 기능에서 활용한다.

```text
⭐ 중요
→ Final Note 우선 반영

🔥 시험
→ Quiz 우선 출제

📝 복습
→ 복습 추천

❓ 헷갈림
→ Q&A 설명 우선
```

# 11. Quiz

ClassMind는 학생의 퀴즈 결과에 따라 난이도를 조절한다.

기본 흐름:

```text
Easy
 ↓
70점 이상
 ↓
다음 난이도

70점 미만
 ↓
현재 난이도 유지
```

난이도 예시:

```text
Easy
→ 용어 / 정의

Medium
→ 개념 비교

Hard
→ 상황 적용 / 사례
```

퀴즈 생성에는 다음 정보를 활용한다.

```text
AI Note
+
학생 질문
+
교수님 강조 포인트
+
중요 개념
```

# 13. AI Note 자동 재정리

AI Note가 계속 변경되더라도 매번 전체 노트를 재생성하지 않는다.

DB에 변경량을 기록하고 일정 수준 이상의 변화가 발생하면 재정리를 추천한다.

예:

```text
새로운 질문 증가
+
새로운 보완 개념 증가
+
새로운 주차 추가
```

재정리 시점은 실제 사용 데이터를 확인하면서 조정한다.

또한 다음 조건을 만족하면 재정리를 추천한다.

```text
마지막 생성 후 1주 이상 경과
+
새로운 메모 추가
```

사용자에게:

```text
새로운 메모가 추가되었습니다.
AI 노트를 다시 정리할까요?

[지금 정리]
[나중에]
```

형태로 제공한다.

---

# 14. 변경 기록

AI Note가 변경될 때 간단한 변경 기록을 남긴다.

예:

```text
09/03 Binary Semaphore 개념 추가
09/05 Mutex 설명 보완
09/10 시험 포인트 수정
```

초기 버전에서는 Git과 같은 전체 Diff 시스템을 사용하지 않는다.

목표는 **무엇이 변경되었는지 빠르게 확인하는 것**이다.

# 15. Course 종료

학기가 끝났다고 바로 데이터를 삭제하지 않는다.

```text
Course 종료
    ↓
Archive
    ↓
사용자 선택
 ┌──────────┐
 │ 보관     │
 │ 완전 삭제 │
 └──────────┘
```

Archive 상태에서는 기존 학습 데이터를 유지할 수 있다.

Final Note는 별도의 최종 노트 모음에서 접근할 수 있도록 한다.

# 22. 보안

사용자별 데이터는 서로 분리되어야 한다.

주요 보호 대상:

* Course
* Original Note
* AI Note
* Final Note
* Q&A
* Quiz
* PDF

Supabase Row Level Security(RLS)를 적용하여 사용자가 자신의 데이터만 접근할 수 있도록 한다.

API Key와 DB Secret은 클라이언트에 노출하지 않는다.

AI 요청과 같은 서버 측 작업은 서버 환경에서 처리한다.

# 23. 개발 방향

ClassMind는 처음부터 모든 기능을 완성하는 방식으로 개발하지 않는다.

```text
문제 발견
    ↓
원인 분석
    ↓
최소한의 해결책 설계
    ↓
구현
    ↓
실제 테스트
    ↓
문제 발견
    ↓
설계 개선
```

기능의 개수보다 **각 기능이 어떤 문제를 해결했는지**를 중요하게 본다.

---

# 24. 개발 기록

ClassMind의 개발 과정과 설계 변경은 별도의 문서에서 관리한다.

```text
DEVELOPMENT.md
```

이 문서에는 다음 내용을 기록한다.

* 초기 설계
* 구현 과정
* 발견한 문제
* 문제의 원인
* 설계 변경
* 기술적 선택
* 테스트 결과
* 다음 단계에서 개선할 내용

즉, README가 **현재 ClassMind를 설명하는 문서**라면,

DEVELOPMENT.md는 **ClassMind가 현재 구조까지 발전한 과정을 기록하는 문서**이다.

---

# 25. 현재 목표

ClassMind의 첫 번째 목표는 거대한 AI 학습 플랫폼을 만드는 것이 아니다.

먼저 다음 흐름을 실제로 검증한다.

```text
수업 중
최소한의 메모
      ↓
수업 후
AI가 수업 맥락 이해
      ↓
AI Note 생성
      ↓
학생 질문
      ↓
Living Note에 반영
      ↓
시험 전 Final Note 생성
```

이 핵심 흐름이 실제 학생에게 유용하다는 것이 검증되면 이후 기능을 확장한다.

---

# 26. 향후 확장

MVP 검증 이후 다음 기능을 고려한다.

* 다양한 소셜 로그인
* 학습 통계
* 복습 알림
* 고도화된 RAG
* 과목 간 검색
* 스터디 그룹
* 공유 노트
* 스터디룸
* 사용자 요금제
* 다양한 전공 지원

초기 개발에서는 실제 사용자에게 필요한 기능을 우선하며 불필요한 복잡도를 추가하지 않는다.

---

# 27. 핵심 철학

ClassMind는 학생을 대신해서 공부하는 AI가 아니다.

학생이 수업에서 남긴 작은 메모를 시작점으로

```text
기록
 ↓
이해
 ↓
질문
 ↓
정리
 ↓
복습
```

이라는 학습 과정을 연결하는 것을 목표로 한다.

> **ClassMind는 학생의 작은 메모를 시작점으로 수업 후의 질문과 학습 과정을 하나의 살아있는 노트로 연결하는 AI 수업 비서이다.**
