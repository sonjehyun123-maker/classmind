# StudyNote PRD (Product Requirements Document)

## 프로젝트 개요

StudyNote는 대학생의 최소한의 수업 메모와 강의 PDF를 기반으로 AI가 노트를 생성하고, Q&A와 퀴즈를 통해 학습을 이어가는 AI 수업 비서이다.

## 타겟 사용자

* 1차: CS 전공 대학생
* 이후: 전 학과 확장

## 핵심 가치

* 수업 중 최소 메모
* 수업 후 AI 학습
* Living Note
* Final Note

## MVP 기능

* Google 로그인
* 과목 관리
* 주차별 메모
* PDF 업로드
* AI 노트 생성
* Context Q&A
* Quiz
* Final Note

## 사용자 흐름

수업 → 메모 → AI 노트 → 질문 → Living Note → Final Note
